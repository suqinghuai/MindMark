# 自动阅卷系统 (MindMark)

一个基于AI视觉大模型的自动化阅卷系统，能够自动截图、AI评分、填分并提交，实现批卷流程的全自动化。

## 📋 项目简介

本项目利用Python实现了一个自动化阅卷系统，通过以下步骤完成批量阅卷：
1. **自动截图**：对指定屏幕区域进行截图，获取学生答题内容
2. **AI评分**：调用视觉大模型对答题内容进行智能评分
3. **自动填分**：将AI评分结果自动输入到评分系统
4. **自动提交**：点击提交按钮完成评分
5. **自动翻页**：点击下一题按钮，准备评阅下一份试卷

## ✨ 功能特点

- **全自动化**：从截图到提交全流程自动化，无需人工干预
- **AI智能评分**：利用先进的视觉大模型进行评分，评分标准可自定义
- **交互式坐标配置**：支持实时点击获取坐标，配置更简单直观
- **交互式启动**：等待用户确认后开始阅卷，避免误操作
- **可视化日志**：使用emoji图标的友好日志输出，状态一目了然
- **评分标准独立**：评分标准从单独的markdown文件读取，便于维护
- **日志记录**：详细的日志记录，方便查看评分过程和结果
- **异常处理**：具备完善的异常处理机制，确保系统稳定运行
- **紧急停止**：鼠标移至屏幕左上角可紧急停止，保障系统安全
- **配置灵活**：通过配置文件可灵活调整各项参数

## 🛠️ 技术栈

- **Python 3.12+**
- **第三方库**：
  - `mss` - 高性能屏幕截图
  - `Pillow` - 图像处理

## 📦 使用步骤

双击运行MindMark.exe即可启动系统。

## ⚙️ 配置说明

项目使用 `config.ini` 文件进行配置，同时支持从 `评分标准.md` 文件读取评分标准。

### 1. 基础配置 (`[basic]`)
- `loop_count`：循环阅卷次数（0表示无限循环）
- `step_delay`：每步操作间隔（秒）
- `log_dir`：日志保存目录

### 2. 截图配置 (`[screenshot]`)
- `region_left`、`region_top`：截图区域左上角坐标
- `region_width`、`region_height`：截图区域宽度和高度
- `save_dir`：截图保存目录

### 3. AI配置 (`[ai]`)
- `api_key`：API密钥
- `base_url`：API接口地址
- `model`：使用的AI模型
- `max_retries`：API调用最大重试次数

### 4. 自动化配置 (`[automation]`)
- `score_input_x`、`score_input_y`：分数输入框坐标
- `submit_btn_x`、`submit_btn_y`：提交按钮坐标
- `next_btn_x`、`next_btn_y`：下一题按钮坐标

### 5. 评分标准文件 (`评分标准.md`)
- 独立的markdown文件，包含详细的评分标准
- 支持中文格式，便于阅读和维护
- 系统启动时会自动读取并应用到AI评分中

## 🚀 使用方法

1. **配置调整**：根据实际情况修改 `config.ini` 文件中的各项参数
   - 使用截图工具（如微信截图）获取准确的坐标值
   - 确保API密钥有效且有足够的调用额度
   - 编辑 `评分标准.md` 文件自定义评分标准

2. **启动系统**
   ```bash
   MindMark.exe
   ```

3. **坐标配置选择**：
   - 系统启动后会提供两个选项：
     - **选项1**：使用原有坐标配置（从config.ini读取）
     - **选项2**：重新获取坐标配置（交互式点击获取）
   - 如选择选项2，系统会引导您依次点击：
     - 截图区域左上角和右下角
     - 分数输入框位置
     - 提交按钮位置
     - 下一题按钮位置
   - 点击后立即记录坐标，无需等待
   - 新坐标会自动保存到config.ini文件

4. **交互式启动**：
   - 系统启动后会等待用户输入指令
   - 输入 `s` 开始阅卷，输入 `q` 退出程序
   - 确保已切换到阅卷浏览器窗口后再开始

5. **系统运行**：
   - 使用emoji图标的友好日志输出，状态一目了然
   - 系统会自动开始截图、AI评分、填分、提交、翻页的循环
   - 运行过程中会在控制台和日志文件中输出详细信息

6. **停止系统**：
   - 按 `Ctrl+C` 手动终止
   - 或鼠标移至屏幕左上角触发紧急停止

## 📊 评分标准

系统从 `评分标准.md` 文件读取评分标准，支持自定义评分规则。默认评分标准如下：

```markdown
内容切题（4 分）：紧扣题目，有明确观点或情感，内容完整；跑题、内容空洞酌情扣分。
结构逻辑（3 分）：段落清晰，语句连贯，逻辑通顺；结构混乱、语病多酌情扣分。
语言表达（2 分）：用词准确，无明显错别字和标点错误；文笔粗糙、错字多酌情扣分。
字数合规（1 分）：字数在 180-220 字之间，超出或不足扣 1 分。
打分参考：
8-10 分：切题、完整、通顺、优美，字数合规。
5-7 分：基本切题，结构清晰，语言通顺，存在少量问题。
1-4 分：跑题、内容残缺或语病较多，需大幅修改。
0 分：完全跑题或无有效内容。
```

**修改评分标准**：
- 直接编辑 `评分标准.md` 文件即可
- 支持中文格式，便于阅读和维护
- 系统启动时会自动加载最新的评分标准

## 🔒 安全注意事项

1. **API密钥安全**：请妥善保管 `config.ini` 文件中的API密钥，避免泄露
2. **坐标准确性**：使用前请仔细校准各项坐标值，避免误操作
3. **系统稳定性**：运行过程中避免操作鼠标和键盘，以免干扰自动化流程
4. **紧急停止**：如发现异常，立即将鼠标移至屏幕左上角触发紧急停止

## 🔧 故障排除

1. **截图失败**：检查截图区域坐标是否正确，确保目标区域在屏幕可见范围内
2. **AI评分失败**：检查API密钥是否有效，网络连接是否正常
3. **自动化操作失败**：检查坐标值是否准确，目标按钮是否可见
4. **系统无响应**：按 `Ctrl+C` 手动终止，或重启系统
